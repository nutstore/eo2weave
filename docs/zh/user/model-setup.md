# 配置 AI 模型

本教程介绍如何配置 AI 服务商、常用模型，以及设置全局默认模型。完成这三步后，你就可以在对话中直接使用 AI 了。

## 概览

怡氧知知的模型配置分为三层，理解它们的关系能帮你少走弯路：

| 层级 | 作用 | 配置位置 |
|------|------|----------|
| ① 服务商 API Key | 证明"你有权限调用这家 AI" | 设置 → LLM 服务商 |
| ② 常用模型（可选） | 从服务商的众多模型里挑出你常用的几个，方便快速切换 | 设置 → LLM 服务商 → 服务商卡片 |
| ③ 默认服务商和模型 | 全局默认：每次新建对话用哪个模型 | 设置 → LLM 服务商 → 默认模型，或顶栏模型切换器 |

> 三层的关系：Key 是"通行证"，常用模型是"收藏夹"，默认模型是"当前正在用的那一个"。只有 Key 而没选默认模型时，对话无法开始。

## 第一步：配置服务商 API Key

1. 点击顶栏右侧的 **设置**（齿轮图标）
2. 在左侧导航选择 **LLM 服务商**
3. 在服务商列表中找到你要使用的服务商（如 OpenAI、Anthropic、智谱 GLM、DeepSeek 等），点击展开卡片
4. 在 **API Key** 输入框粘贴你的 Key（在服务商的开放平台后台创建）
5. 点击 **保存**

展开卡片后你还可以：

- **刷新模型列表**：点击"我的模型"旁的刷新图标，从服务商的 `/models` 接口拉取真实可用的模型列表
- **配置多个服务商**：重复上述步骤即可，每个服务商独立保存 Key

> 💡 推荐使用坚果云 AI：在欢迎页点击"用坚果云账号登录"即可一键完成，无需手动管理 API Key。

> 💡 想用本地模型（数据不出本机、零成本）？参见 [接入 Ollama 本地模型](./ollama.md)。

## 第二步：添加常用模型（可选）

常用模型是你收藏的模型子集。配置后，顶栏的模型切换器只显示这些模型，切换更快；不配置的话，切换器会显示服务商的全量模型清单。

1. 在 **LLM 服务商** 页展开已保存 Key 的服务商卡片
2. 找到 **我的模型** 区域：
   - 点击 **从 API 添加**：从拉取到的模型列表里勾选（推荐，名字准确）
   - 或点击 **手动添加**：直接输入模型 ID（适用于 API 列表里没有的新模型）
3. 添加的模型会以标签形式展示，点击标签上的 × 可移除

## 第三步：选择默认服务商和模型

这一步**必须有**，否则发送消息时会提示"模型未配置"。有两种入口：

### 方式一：设置页（推荐首次配置使用）

1. 在 **LLM 服务商** 页顶部的 **默认模型** 下拉框中
2. 先选服务商分组，再选一个模型
3. 关闭设置即可生效

### 方式二：顶栏模型切换器（日常切换用）

1. 点击顶栏的 **模型切换器**（✦ 图标按钮，显示当前模型名）
2. 在弹出的面板中按服务商分组选择模型
3. 选择后立即生效，新建对话即使用该模型

> 侧边栏/窄屏模式下，模型切换器同样直接显示在顶栏上。

## 验证配置是否成功

- 顶栏的"未配置 API Key"警告已消失
- 顶栏模型切换器显示的是"服务商 / 模型名"（例如 `OpenAI / GPT-4o`），而不是"模型不可用"
- 欢迎页的设置引导卡已消失，输入框可以输入并发送

## 常见问题

### 已经配置了 Key，为什么提示"模型未配置"？

Key 只解决了"通行证"，还需要选择**默认服务商和模型**（见第三步）。打开设置 → LLM 服务商，在顶部"默认模型"里选一个即可。

### 切换器里看不到我想要的服务商？

确认该服务商的卡片已展开且 Key 已保存（卡片左侧圆点为绿色）。若保存 Key 时该服务商的模型列表为空，也会暂时不显示——刷新模型列表后再试。

### 如何更换默认模型？

随时点击顶栏模型切换器换模型，或回到设置页的"默认模型"下拉框调整。你上次用的模型会被记住，下次切回该服务商时自动恢复。

### API Key 存在哪里？

Key 加密保存在本地浏览器的 SQLite 数据库中，不会上传到任何服务器。参见[数据备份与迁移](./backup.md)了解如何迁移到新设备。
