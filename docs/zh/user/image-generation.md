# 图片生成

怡氧知知支持在对话中直接生成图片:你用自然语言描述想要的画面,AI 调用图像模型生成图片并放进对话,还能作为插图写进文档。不需要任何斜杠命令。

## 支持哪些服务商(重要)

**目前只有 OpenRouter 风格的服务商支持图片生成。**

| 你的服务商类型 | 能否生图 | 说明 |
|----------------|----------|------|
| OpenRouter(或 OpenRouter 风格的中转站,模型列表里包含图像模型) | ✅ 可以 | 图像模型会出现在模型选择器里 |
| OpenAI / Anthropic / 智谱 GLM / DeepSeek / Codex / Ollama 等 | ❌ 暂不支持 | 界面上不会出现图片生成入口 |

**判断方法**:图片生成的模型来源是服务商模型列表里的图像模型。如果展开服务商卡片、刷新模型列表后,顶栏的图像模型选择器没有出现,说明当前服务商暂不支持。

> 原因说明:图片生成依赖"在服务商的模型列表中精确匹配到图像模型"这一机制。目前仅 OpenRouter 风格的 `/models` 接口会返回图像模型(如 `google/gemini-3.1-flash-image` 系列);其他服务商的列表里没有可匹配的图像模型,功能整体保持隐藏,而不是报错。
>
> 对自定义中转站的支持(手动填写图像模型 ID)已列入后续计划。

## 如何生成图片

**方式一:直接对话(推荐)**

在输入框里用一句话描述,例如:

- 「画一只橘色的猫,水彩风格」
- 「帮我生成一张 16:9 的赛博朋克城市夜景」
- 「给这篇文章配一张封面图:雪山脚下的森林小屋」

AI 会直接调用图像模型生成,图片显示在对话中,并保存到本地资产。

**方式二:输入区的「生成图片」快捷入口**

输入框上方有一个「生成图片」小胶囊,点击会预填一句示例,补全描述后发送即可。不用时可以点 × 关闭(记住选择,不再显示)。

## 宽高比

顶栏的图像模型选择器(🖼️ 图标)里除了选模型,还可以选宽高比:1:1 / 16:9 / 9:16 / 4:3 / 3:4 / 3:2 / 2:3。

- 对话里直接说比例也可以,例如「画一张竖版海报」会自动选 3:4
- 不指定时由 AI 根据内容自行判断

## Plan 模式下也能用

图片生成不需要切换到 Act 模式——它只会把生成的图片写入资产目录,不会修改你的工作区文件,所以 Plan(只读)模式下同样可以直接生图。

## 图片保存在哪里?

生成的图片保存在本机浏览器资产目录(OPFS),不会上传到任何服务器。可以在对话中通过资产面板查看,删除对话不会删除已生成的图片。

## 常见问题

### 我看不到「生成图片」入口?

最常见的原因是**当前服务商不支持**(见上文表格)。确认你配置的是 OpenRouter 或其兼容中转站,并且:

1. 已在设置 → LLM 服务商保存 API Key
2. 已展开服务商卡片并**刷新模型列表**(生图能力依赖拉取到的模型列表)
3. 顶栏出现图像模型选择器(🖼️)

三个条件都满足时,输入区上方才会出现「生成图片」入口——这是刻意设计:入口只在真正能用时出现,不会给你一个点了报错的按钮。

### 点击生成后报「模型不可用」?

你选择的图像模型可能已下线,或你的中转站没有实际上架该模型。在顶栏图像模型选择器里换一个图像模型再试。

### 生成失败,提示内容安全相关?

图像模型会拒绝明显违规的描述。换一种描述方式重试。

### 用量怎么算?

图像生成按你所用服务商的计费规则单独计费(通常高于文本对话),生成前请确认所选模型的定价。定价展示功能已在计划中。
